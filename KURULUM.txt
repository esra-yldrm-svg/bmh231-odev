# Bilgisayarda çalıştırma

1. Bu ZIP'i çıkar.
2. `bmh231-odev1` klasörünü VS Code ile aç.
3. Terminali bu klasörde aç.
4. Node.js LTS kurulu değilse kur.
5. Şunları çalıştır:

npm install
npm start

6. Tarayıcıda:
http://localhost:3000

7. Testleri README.md içindeki curl komutlarıyla yap.

Önemli:
- `node_modules` ZIP'e konulmamıştır. `npm install` oluşturur.
- GitHub kullanıcı adını README ve rapordaki yer tutucularda değiştir.
- Öğrenci numaranı ekle.
- Bölüm B ölçümlerini kendi bilgisayarında yap.
- Bölüm D'ye kendi Timing sonuçlarını ekle.
- Son PDF'yi hocanın istediği dosya adıyla BOYSİS'e yükle.
